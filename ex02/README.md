# Primitive datatypes

Primitive datatypes are also called Scalar data types.

These datatypes are:
- int
- float
- bool
- char

## int
Rust has signed and unsigned integers of different sizes

Signed integers
- i8
- i16
- i32
- i64
- i128

Unsigned integers
- u8
- u16
- u32
- u64
- u128

## float

Floats are
- f32
- f64

## bool

Either 'true' or 'false'

## char

- character
