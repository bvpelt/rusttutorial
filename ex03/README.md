# Compound datatypes

The compound datatypes are:
- arrays
- tuples
- slices
- strings
- slice string

## Arrays

Arrays are a fixed size collection of the same type.

## Tuples

Tuples contain a fixed size collection of mixed types.

## Slices

A contiguous peace of memory with the same types

## String Slices (&str)

Strings can grow and increase, they are mutable. They are owned types.
In RUST any datatype is by definition immutable, except for String.
